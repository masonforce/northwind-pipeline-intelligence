# Execution evidence

Text evidence that this build actually ran end to end. These are committed outputs (logs, query
results, model output), not screenshots, so they can be read directly.

Two infra identifiers are redacted to neutral placeholders: the Unity Catalog shows as
`fe_demo_catalog` and the workspace as `example-workspace`. Every count, query result, and model
output below is the real build output. All data is synthetic, generated by the scripts in the repo
root (seed 42); there is no customer data.

The planted findings come back as designed: Solution is the slowest funnel stage, the ERP integration gap concentrates in NetSuite, win rate varies by lead source, inbound demand spikes at the 9/30 launch, and anchor deal OPP-01042 is lost to the ERP gap. |
